El error de cada punto es su distancia a la recta.

MAE

Error promedio

Cuánto se equivoca en promedio, en USD. Menor es mejor.

RMSE

Error cuadrático

Como el MAE, pero castiga más los errores grandes.

R²

Varianza explicada

De 0 a 1. 1 = perfecto; 0 = predecir siempre el promedio.

01

Regresión: predecir un número

Dos modelos

En el notebook entrenamos dos modelos con los mismos datos para comparar uno simple con uno más complejo.

Regresión lineal

Cómo predice
Traza una sola recta que pasa lo más cerca posible de todos los puntos.
A favor
Cada coeficiente dice cuánto sube o baja el precio.
En contra
Si la relación no es recta, como pasa con la ubicación, se le escapa.

Random Forest

Cómo predice
Junta muchos árboles de decisión. La casa pasa por cada árbol, que le hace preguntas y llega a un precio. La predicción final es el promedio de todos los árboles.
A favor
Se adapta a relaciones que no son rectas.
En contra
Es más difícil explicar por qué da cada número.
01

Regresión: predecir un número

El código
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score

# 1. Separar: X = variables, y = lo que queremos predecir
X = df.drop(columns="median_house_value")
y = df["median_house_value"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 2. Entrenar (preprocesamiento + modelo en un Pipeline)
modelo = Pipeline([("prep", preprocesamiento),
                   ("modelo", LinearRegression())])
modelo.fit(X_train, y_train)

# 3. Predecir sobre datos que nunca vio
pred = modelo.predict(X_test)

# 4. Evaluar
mean_absolute_error(y_test, pred)   # ≈ 50.750 USD
r2_score(y_test, pred)              # ≈ 0,65

02

Clasificación: predecir una categoría

Cómo calcula la probabilidad
  1. Al entrenar, el modelo mira pasajeros de los que ya sabemos si sobrevivieron, y aprende cuánto suma o resta cada dato.
  2. Para un pasajero nuevo, suma esos puntos.
  3. Una curva convierte el puntaje en una probabilidad entre 0 y 1.
  4. Si la probabilidad pasa el umbral, predice «sobrevive».
Pasajera
mujer +1ª clase +38 años −
probabilidad ≈ 0,90 → predice: sobrevive
Pasajero
hombre −3ª clase −22 años +
probabilidad ≈ 0,10 → predice: no sobrevive

Clasificación: predecir una categoría

El código
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report

X = df.drop(columns="survived")
y = df["survived"]                       # 0 o 1
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y)     # misma proporción en train y test

modelo = Pipeline([("prep", preprocesamiento),
                   ("modelo", LogisticRegression(max_iter=1000))])
modelo.fit(X_train, y_train)

pred = modelo.predict(X_test)                # 0 o 1, con umbral 0,5
prob = modelo.predict_proba(X_test)[:, 1]    # probabilidad de sobrevivir
pred_03 = (prob >= 0.3).astype(int)          # otro umbral, como en la demo

print(classification_report(y_test, pred))
  • predict_proba entrega la probabilidad de sobrevivir de cada pasajero. Es lo mismo que muestra el eje horizontal de la demo.
  • Con stratify=y, train y test quedan con la misma proporción de sobrevivientes (38%).

Clustering: encontrar grupos

El código
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

variables = ["bill_length_mm", "bill_depth_mm",
             "flipper_length_mm", "body_mass_g"]
X = df[variables]                        # sin y: no hay respuesta
X_scaled = StandardScaler().fit_transform(X)

# Elegir k: probar varios y mirar la inercia (método del codo)
for k in range(2, 9):
    km = KMeans(n_clusters=k, n_init=10).fit(X_scaled)
    print(k, km.inertia_)

kmeans = KMeans(n_clusters=3, n_init=10)
df["cluster"] = kmeans.fit_predict(X_scaled)

# Verificar con la especie (solo porque la conocemos)
pd.crosstab(df["species"], df["cluster"])
  • Aquí no se usa train_test_split, porque no hay una respuesta correcta con la cual comparar.
  • n_init=10 repite el algoritmo con 10 centroides iniciales distintos, como el botón «Nuevos centroides» de la demo.
